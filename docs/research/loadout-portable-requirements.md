# Loadout 可迁移需求包

日期：2026-10-29。用于完整产品替换的验收，不要求复刻 Loadout。用户已接受更换界面与操作方式，优先少维护。

2026-10-30评估更新：用户再次明确技术实现服从少维护。[041原生SQLite路线](2026-10-30-omniroute-native-sqlite-assessment.md)不将RouteSnapshot、热路径零SQL、旧栈/命令或旧性能预算列为可迁移保证；保留凭证保护与账号行为，并按实际消费者检验正确性。下表中的ADR用于追溯行为来源，不应被解释为搬迁其全部实现。评估阶段没有授权修改生产或自动执行下一轮测试。

安全底线和账号规则保持有效；实现语言、GUI、CLI 命令、URL 前缀、Named Pipe、SQLite 表结构可以调整。涉及现有强制架构规则的正式替换，应另行修订 ADR。本包不授权读取真实凭证或切换生产。

## 必须承接的行为

| ID | 行为与验收 | 现有依据与证据等级 |
|---|---|---|
| R01 | Windows 10/11 x64 本地运行；管理窗口关闭后客户端仍可用；重启恢复配置；可禁用自启并回滚 | ADR-001/002，现有产品架构；候选运行未验证 |
| R02 | 同一 Provider 下多个账号；受限入口可使用裸模型名；点名账号优先且不参与轮转，默认仍可同模型换账号，禁用account failover时固定；新账号进入主集合、不会自动进入已定义子集 | ADR-003 §8、ADR-010/015、ExecPlan 019；2026-10-29据table.rs/select.rs纠正原“不自动换号”简化表述 |
| R03 | 同模型有序 failover：首选成功时持续使用；429/额度耗尽按账号冷却；一个账号的两个协议入口不应耗光其他账号的尝试机会；剩余预算允许时能到达后续健康账号 | 034 的真实设备故障记录及修复回归；并非本轮重跑 |
| R04 | 显式开启后每个请求换下一个可用账号；关闭时恢复顺序；会话头不能悄悄覆盖轮转；点名账号例外保持固定 | 035 自动化集成与 benchmark；明确未真实商汤流量验证 |

| R07 | 推理入口强制鉴权，错误/缺失 key 被拒绝；本地监听与管理接口权限独立；Provider secret 只在 OS 保护存储，DB 只存引用；client key 持久化不含原文 | ADR-004/011，安全底线，不因换产品降低 |
| R08 | 请求/响应正文、tool 参数、认证头默认不落盘；错误和日志不含 secret；加密/解密失败必须拒绝不安全操作，不能退回明文 | ADR-004/008；包含数据库、WAL、备份、日志与导出路径 |

原有 TTFT 档位算法、精确 CLI 命令、Loadout 名称、Tauri、Rust、所有实验接入都不是默认必须搬迁的资产。产品原先的更大愿景也不等于当前用户已验证的需求。活动中的010/017/030不能自动当作完整稳定能力。

## OmniRoute 映射与待确认项

基准为 v3.8.52，不把开发分支新增功能当作发布版能力。以下属于拟验证的配置/适配方案。

| 需求 | 首选方式 | 尚需证明 |
|---|---|---|
| R02/R05 | API key 的 allowedConnections、模型映射；主集合与子集合配置 | exact/组合/恢复/备用路径均不能越权；新账号集合语义；多个客户端切换一致性 |
| R03 | 原生 fill-first、priority、账号 fallback/cooldown | 三账号429场景；同 key 跨协议冷却；等待期限与取消 |
| R04 | provider 策略 round-robin，批次大小调整为1，关闭影响该入口的 affinity | LRU 实现是否满足顺序；串行 a,b,c,a；并发不错误超发；stateful 请求不误轮转 |
| R06 | 显式模型与限定组合，禁用跨模型/智能降级 | 无可用同模型时拒绝，不能另找相近模型 |
| R07/R08 | 入口安全配置；集中凭证适配；关闭正文及 pipeline 日志 | 所有读写/刷新/备份路径；保留 OS store 与 secret_ref；失败不写明文 |
| R09 | 上游原生协议实现 | tool/SSE/取消/有状态会话完整验收，不能用非流式 Hello World 代替 |
| R01/R13 | 上游 Windows 包与独立服务启动方式 | 关闭 GUI、重启、崩溃重启、更新回滚、隔离实例不冲突 |
| R10/R11 | 上游导入导出/仪表盘，必要时单次迁移工具 | 加密格式与覆盖语义、metadata 可用、导出不泄漏 |

凭证适配属于主要未知成本，不能估计成“改一行环境变量”。如果需要改动许多业务模块才能满足它，首选理由将变弱。数据库密文加 OS 保护主密钥可另提 ADR 评估，当前不替代 R07。

## 隔离验收顺序

配套 [JSON 验收向量](product-foundation-acceptance-cases.json) 是合成输入与预期，不是已执行测试结果。使用 a/b/c 假账号、同一 mock-model-v1，mock 上游记录实际命中账号、模型、次数和连接关闭。

1. **安全落盘**：在临时环境导入假 key，模拟保护存储不可用/加密失败；检查 SQLite/WAL、配置、日志、备份、导出、异常信息。正常路径仅有引用，失败路径不出现原文和降级保存。
2. **访问边界**：缺失/错误 client key；子集只有 b,c，尝试 exact a、组合回退至 a；新增 d；无论名称或路径怎样变化，均不能绕过限制。
3. **账号策略**：a,b 返回429，c成功；协议变体不可耗掉全部账号预算；顺序与每请求轮转分别运行，保持模型不变；冷却后按配置恢复。
4. **协议生命周期**：普通/工具调用 SSE，输出前故障与输出后中断，客户端取消；stateful Responses 跨后续请求保持账号或明确报错。
5. **Windows 使用**：临时启动后关闭管理界面、重启、升级/回滚，客户端与策略保持可用，所有测试系统状态独立且可清理。
6. **维护成本**：在两个发布标签之间升级同一增量，保留改动清单、冲突与测试结果。需要私人协议转换器或另一个路由器时，判定未达到目标。

正式 Loadout 数据目录、端口、Named Pipe、Credential Manager 条目、注册表和客户端配置都不用于上述测试。上游网络访问关闭，默认不执行安装脚本或启动发现功能。候选自己的临时目录/监听参数需先检查，不能直接套用 Loadout 参数名称。

## 迁移交接清单

- 无密钥配置清单：Provider 类别、模型别名、账号逻辑名、子集、顺序、轮转开关、客户端用途；研究期间不从正式环境导出。
- 安全配置清单：监听、鉴权、存储、日志、发现/同步/远程控制禁用项。
- 假账号验收结果与两版本升级记录。
- 后续授权后生成的加密迁移文件、导入校验结果及回滚步骤。
- 私人补丁清单：每项有上游版本、改动边界、理由、测试、可否提交上游；不打包 Loadout 全部源代码当作迁移需求。
