# 054 原生只读目录、用量与路由诊断

本轮仅在OmniRoute v3.8.52固定底座（`ad6f33f66bda34eba98645d3bfdabbde294bc843`）开放原生只读管理能力。不做UI、不触碰正式安装/数据/凭据、不调用真实Provider或启动实际客户端，无提交上传。

## 接通的能力

| 能力 | 原生接口 | 数据含义与边界 |
|---|---|---|
| 静态模型与可用标记 | `GET /api/models` | 原生目录，不是账号实测成功清单；`all=true`可看完整静态目录。 |
| 已保存的自定义模型与能力覆盖 | `GET /api/provider-models?provider=...` | 读取当前原生配置；不开放新增、验证、同步或删除模型。 |
| 用量与成本汇总 | `GET /api/usage/history` | 原生已记录请求/token、Provider/模型/账号/client key分组、估算成本；不代表余额或实际账单。成功的非流式上游响应未提供usage对象时，原生usage history不记该次用量，不能作为全HTTP请求审计总数。慢查询可能缓存最多60秒，原生`x-analytics-cache`区分命中。 |
| 模型延迟统计 | `GET /api/usage/model-latency-stats` | 沿用原生时间窗口、最小样本与行数限制。 |
| 调用索引 | `GET /api/usage/call-logs` | 账号、模型、状态、token、耗时、关联ID等元数据；未开放正文详情或导出接口。 |
| 单次路由解释 | `GET /api/usage/route-explain/<id>` | 同时包含持久化运行元数据与按当前状态重算的解释；保留confidence/limitations和`exactRuntimeReplay=false`等语义。原生`costActual=0`占位不能解释为免费。 |
| 实际combo调用轨迹 | `GET /api/usage/combo-trace/<id>` | 响应头`X-OmniRoute-Combo-Trace`给出ID；原生进程内30分钟TTL、最多2000条，重启/过期后404。 |

操作沿用`fusion.cmd admin INSTANCE GET /api/...`，无需新查询服务。管理接口是全局管理员视图，普通推理key不能读取它们；客户端自己的模型目录仍用原生`/v1/models`及其权限过滤。

## 最小改动

只修改既有`src/proxy.ts`的管理入口白名单及方法约束，选定接口仅GET/HEAD，其余写方法拒绝；不新增API handler，不修改原生统计写入、SQL/schema、Router或协议转换。`fusion/backup.mjs`增加限定的053→054适配版本对；`fusion/runtime.mjs`仅为选定只读GET路径允许query参数，其他路径/写方法仍拒绝query；随包README记录命令与数据含义。

所有查询和聚合实现均来自OmniRoute的原生route、`src/lib/usage/`、`src/lib/db/`和`open-sse/services/combo/decisionTrace.ts`，沿用MIT许可，已更新来源表与THIRD_PARTY_NOTICES。保持原有`noLog`和正文日志关闭：它们阻止正文落盘，不阻止原生元数据统计，因此无需另建采集链路。

## 测试中发现的问题

- 首轮异常Host用例使用Node fetch，但fetch会按URL重写Host，实际发出的不是异常Host。沿用已有management测试的原始HTTP写法后通过；无需修改产品。首次结果保存在失败回执。
- 升级测试沿用旧mock，未返回usage对象。按原生`recordNonStreamingUsageStats`语义不会写usage history；旧、新数据库用量行均为0，不能把它解释为升级丢数据。修正mock为11输入/7输出，增加升级前已有行和升级后22/14 token的精确断言；产品统计实现未改。见首次升级结果和诊断记录。
- 第二轮升级检查暴露实际工具问题：`Instance.admin`禁止所有query，导致参数查询报ADMIN_PATH。限定放行所选只读GET路径后重封工具；没有修改原生handler。新增通过随包CLI读取provider过滤、最小样本和limit参数的检查，同时验证其他管理路径及写方法不能借query放行。见失败回执。
- 新增合成上游错误回显`api_key=...`反例，检查原生脱敏后的查询结果与实例文件；这是对可识别凭证字段的验证，不等于任意上游自由文本都能被完整脱敏。
