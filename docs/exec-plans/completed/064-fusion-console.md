# ExecPlan 064 — 后端收口与融合控制台

## Goal
补齐后台默认安全开关，交付连接真实 OmniRoute 管理接口的控制台，并完成 UI/UX 实际操作自审。

## Context / Existing behavior
沿用 v3.8.52、058.1 全部适配及现有迁移/备份。061 发现健康检查不受通用后台开关控制，逐账号 0 只是实例保护。最新用户授权继续后端开发并开始 UI，取代之前功能冻结和不做 UI 的限制。

## Constraints
少维护；正式安装、数据与凭据不动，不提交上传。默认别名、订阅转发、GPT 池保持禁用。不扩大真实调用或客户端调试。仅保留一个候选 ZIP。2026-11-01 用户新一轮明确授权清理后，重新核验旧展开包和本次构建缓存的范围再删除；若再次拒绝则保留，不换路径绕过。

## Architecture impact / Existing abstractions
一个 OmniRoute 后台；React 静态控制台同源消费原生 cookie/CSRF 管理 API。不新增代理、数据库、路由器、指标服务。复用原生环境开关禁用 credential health check。流向图消费实际调用元数据，不把配置示意或重算冒充实时轨迹。

## Files expected to change
fusion 启动/管理工具；apps/fusion-console；scripts/fusion 静态构建/打包接线；tests/fusion；ADR-019、reference-map、状态与报告。不改推理调度。

## Implementation stages
1. 原生探测总开关、默认新账号与重启验证。
2. 登录、流量/用量、账号管理、路由查看、原生目录/同步。
3. 原生接口集成、类型/构建检查、Windows 浏览器操作和截图自审。
4. 更新唯一候选、回归已有安全/账号规则并记录剩余项。

## Tests / Performance validation
本地 mock 和隔离实例，无真实推理调用。超过 30 秒启动窗口后及重启后检查探测数量；验证登录/CSRF/凭证脱敏/静态资源/空与错误状态。无热路径变更，不跑 Rust benchmark。原生只读查询不得触发 Provider。

## Security considerations
密码/凭据仅表单内存及原生接口，不存 localStorage、日志或截图。浏览器仅本机隔离端口。UI 不提供无保护的订阅/GPT/默认启用捷径。未知统计不当作免费或余额充足。

## Migration considerations
SQLite schema 不变。发现创建账号也会自动探测后，增加一个管理入口条件并重新编译；直接在本次 standalone 目录装配验证，不再复制一个包。候选版本变动需通过既有迁移机制处理 baseline，不绕过包身份校验。

## Known risks
原生统计有窗口/缓存限制；新控制台不是全部上游 UI。商汤风控、CommandCode 401、WorkBuddy 自然轮换延期不变。完整新底座升级证据仍待补。

## Definition of done
真实接口控制台可运行；默认探测关闭有运行证据；核心交互自审/构建通过；唯一候选可校验；明确剩余限制。
