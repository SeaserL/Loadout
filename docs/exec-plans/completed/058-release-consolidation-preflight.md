# ExecPlan 058 — 发布收口与实际迁移预检

> 关闭于 2026-11-03：发布入口和预检已并入 067 与 1.0。下面未勾选的一项是当时被拒绝的临时目录清理，不再跟进。

## Goal
冻结057网关功能，将构建、打包、回归及清理收敛成一个入口；只读核对实际旧池、账号绑定与默认别名，报告缺口而不猜测迁移目标。

## Context
用户授权发布流程收口和实际迁移预检；不做UI、不动正式环境、不提交上传，只保留一个候选。外部账号故障及客户端调试继续延期。

## Existing behavior
057最终包232项已验；运行包独立，但构建/测试脚本分散在实验目录。既有snapshot/preview/inventory/compile可复用，旧启用账号和别名必须显式映射。

## Constraints
不增加Provider/路由/预算等业务能力。不读取真实密钥、不发真实推理、不触发登录或修改客户端。正式SQLite只读事务查询；输出账号使用稳定脱敏引用，禁止导出秘密或个人标识。

## Architecture impact
不改OmniRoute运行时补丁。规范工具依赖和连接器来源路径、合并现有回归入口；外围工具只补预检与当前候选升级对。

## Files expected to change
scripts/fusion-release.ps1、scripts/fusion/、tests/fusion/、development/fusion/、fusion/vendor/、fusion/backup.mjs及相关操作/来源/验收文档。历史evidence保留。

## Implementation stages
1. 固定输入与目录归属，建立单一发布入口及依赖/notice来源。
2. 复用现有迁移逻辑完成只读预检，核对旧池、账号与默认别名。
3. 一次从源码构建、封包、最终包集中回归及057→058升级恢复。
4. 审计测试凭据/进程、清理缓存和旧包、保存小型验收记录。

## Tests
预检使用脱敏fixture验证未绑定、未知别名、禁用成员和来源变化；生产源只读，不用mock绑定冒充真实绑定。复用057的232项功能回归，按新包身份重新记录。单入口检查失败不推广候选。

## Performance validation
网关热路径冻结，沿用集中回归的完整HTTP mock benchmark，不新增性能框架。

## Security considerations
隔离路径、端口、OS vault前缀与出站guard保持。正式源不写入、不读取凭证列、不读正式vault。清理仅限验证过的绝对路径，拒绝链接与不明确归属。

## Migration considerations
预检不是迁入；API key/受控登录/桌面绑定分别列状态。默认别名不由测试值或推荐策略代填。仅增加精确057→058升级对，不解除隔离保护。

## Known risks
构建源仍是未提交工作副本，不宣称GitHub可恢复；首次统一流程可能暴露路径假设。真实账号绑定不足与外部账号故障分开。原生全量typecheck及未来上游升级仍不在本轮证明范围。

## Definition of done
一个命令完成发布链；新包集中回归通过且只留一个ZIP；实际迁移预检产生可执行缺项清单；源码/未提交修改与正式环境完整保留。
