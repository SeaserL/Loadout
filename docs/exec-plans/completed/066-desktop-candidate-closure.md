# 066 — 桌面候选包收口

> 关闭于 2026-11-03：被 067 取代。用户否定了这个候选，下面未勾选的项不再跟进。

## Goal
将 065 的界面与 Windows 窗口/托盘装入唯一候选包；验证完整包的启动、窗口隐藏恢复、退出、后台重启和 064→066 升级。冻结功能。

## Context / Existing behavior
064.1 为当前后台候选包；065 的界面和 Tauri 壳在开发预览目录，尚未打入候选包。此前桌面进程启动被自动审批拦截，原生交互尚未验收。

## Constraints
不动正式安装/数据/8317，不提交上传，不访问真实 Provider。不启用默认别名、订阅转发或 GPT 池。保留源码及未提交修改，只留一个候选 ZIP。审批拒绝不得换工具绕过。

## Architecture impact
沿用 ADR-019 隔离控制面和 ADR-002 独立后台。静态 UI 由现有后台同源提供，无 Vite 服务。桌面启动脚本复用现有 Instance.start，不增加 Provider 或路由接口。关闭窗口隐藏到托盘；托盘退出只退出控制面，后台由现有管理工具停止。

## Files expected to change
fusion/desktop.mjs、桌面启动脚本与 README；scripts/fusion/assemble.mjs、config.mjs；backup.mjs 的明确升级对；desktop preview 标题/子系统；桌面包验收与发布证据。

## Implementation stages
1. 封装桌面启动、停止和既有管理入口，原生窗口使用打包后的同源 UI。
2. 校验后复用未变化的已编译后端，打入界面和桌面二进制，封印 manifest。
3. 完整包回归、064→066 合成升级/恢复与后台重启。
4. 原生窗口/托盘交互验收；如被审批拦截，记录未验收项及准确手动步骤。
5. 唯一候选包替换和有界缓存清理，保留证据与必要运行目录。

## Tests
沿用 247 项完整包隔离回归；补充桌面启动入口、同源资源、无开发服务依赖、重复启动、停止重启、路径边界验证。原生窗口/托盘验收独立记录，不以浏览器测试代替。

## Performance validation
不改 Router/Gateway；复用当前套件已有性能回归，不增加基准工程。

## Security considerations
秘密沿用 Windows Credential Manager；启动输出只包含状态与非敏感路径。启动器不自动导入生产账号，不绕过登录。默认隔离目录位于包外。

## Migration considerations
只允许已验证 064.1 精确 releaseId 向 066.1 升级。先合成验证，既有 059 隔离实例与正式环境均不自动切换。

## Known risks
Windows 自动审批可能阻止启动或删除缓存；未实际观察的原生行为必须保留为待验收。Tauri 单实例只复用同一隔离桌面窗口，测试前不能有另一隔离桌面会话。

## Definition of done
唯一封印桌面候选包、真实回归证据、升级结果、原生窗口/托盘结果（或明确阻塞）、可执行的用户操作说明，无新增功能或生产变更。

## Decisions
- 不为包装桌面重写后台生命周期，复用 Instance 和现有 CLI。
- 不重编译未变化的 OmniRoute；复用前必须校验封印和源码补丁证据。
- 不将 UI 退出解释为后台退出；托盘文字和说明保持明确。

- 原生首测曾误唤起既有正式窗口，未操作正式窗口或执行正式写入；已修复 TAURI_CONFIG 合并并增加实际编译配置断言与启动前 fail-closed 检查。
- 删除失败首包被自动审批拒绝，不换工具重试；清理入口仅交用户手动执行。
