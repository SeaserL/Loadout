# Loadout

> **All your AI, one endpoint.**

Loadout is a local-first Personal AI Control Plane & Gateway for Windows.

It organizes the AI resources you already have — API keys, API credits, coding-agent subscriptions, local models and compatible gateways — into one observable compute pool, and exposes a single OpenAI / Anthropic compatible endpoint on `127.0.0.1`.

> Status: design phase. Nothing is runnable yet.
